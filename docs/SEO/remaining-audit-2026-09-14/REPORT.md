# Pure Air California — remaining SEO audit

Audit refreshed September 14, 2026. Read-only website/source audit; no website changes or deployment performed.

## Evidence and boundaries

- Crawled all 109 URLs in the live sitemap using direct HTTP requests. All returned 200; all had one H1, matching self-canonicals, unique titles and one nonempty description. No sitemapped page had a noindex meta tag. Extracted JSON-LD parsed successfully. Every extracted img had an alt attribute; this does not establish descriptive quality or image availability.
- Re-ran the existing local static audit: 112/112 sitemap pages, zero errors and warnings. This is an audit of the existing build, not a new build or a guarantee of content quality.
- Live site still differs materially from the September 12 local work. Three additional local case studies are absent from the live sitemap. The SoulCycle case-study URL returns 404.
- Sample redirects pass: HTTP and non-www home URLs redirect with 301 directly to HTTPS www; Brentwood without trailing slash redirects with 301; the legacy residential-air-duct-cleaning URL redirects to its service page. A fabricated URL returns 404; a sampled legacy /libri/ spam URL returns 410.
- Direct live HTML displays 4.6 stars. An earlier search-provider copy showed 4.7; use the fresh direct response for this audit. The current Google Business Profile rating itself was not independently verified.
- No authenticated Search Console, Bing Webmaster Tools, GBP, analytics, server logs, field Core Web Vitals, backlink inventory or location-specific ranking data was inspected. These remain verification work, not confirmed failures.
